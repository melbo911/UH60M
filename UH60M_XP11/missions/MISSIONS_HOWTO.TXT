
The CDU can read FMS (XP flight plan) , FPN (flight plan) and MSN (mission) files.

Fhe files are plain text files which can be create/modified with NOTEPAD.EXE or a similar editor.

When saving a flightplan from te FMS, it will always have the FPN extention.

FPN and MSN files are basically treated the same. The only difference is that a MSN file will start automatically after loading , and the FPN file will start but wait for the first waypoint being selected by the pilot.


A mission can be build from the following list of commands.

 command types:

     0,text                            mission-id

           0,667889

    ------------------------------------------------------------------------------

     1,text                            mission-codename

           1,VALKYRIE

    ------------------------------------------------------------------------------

     2,text                            mission-description

           2,EXAMPLE MISSION

    ------------------------------------------------------------------------------

    10,preset,text,freq                define COM preset

           10,15,Kilo6,123.60

    ------------------------------------------------------------------------------

    11,(preset|freq)                   com1 preset or freq

           11,15

           11,123.60

    ------------------------------------------------------------------------------

    12,(preset|freq)                   com2 preset or freq

           12,15

    ------------------------------------------------------------------------------

    20,preset,text,freq                define NAV preset

           20,8,ILS-LOWI,111.10            NAV preset 8

    ------------------------------------------------------------------------------

    21,(preset|freq)                   set NAV1 preset or freq

           21,8

           21,ILS-LOWI,111.10

    ------------------------------------------------------------------------------
		
    22 nav2 preset or freq

    ------------------------------------------------------------------------------

    23,(preset|freq)                   set ADF1 preset or freq

           24,5

           24,123.45

    ------------------------------------------------------------------------------

    24,(preset|freq)                   set ADF2 preset or freq

    ------------------------------------------------------------------------------

    30,preset,text,lat,lon             define location/position preset

           30,11,Konus,48.1789,11.9277

    ------------------------------------------------------------------------------

    31,text,lat,lon,alt,vs             lat/lon location from preset or direct

           31,WPT1,48.3452,11.7496,0,0    ( no alt or vs specified )

           31,11,0,0,0,0                  ( load preset 11 with default ALT and VS )

    ------------------------------------------------------------------------------

    32,text,id,lat,lon,alt,vs          navaid location

           32,Munich,EDDM,0,0,0,0      lat/lon and alt/vs are optional

    ------------------------------------------------------------------------------


    34,text,lat,lon                    load a waypoint into a random location pool

                                       this supports "OSM missions" in regions where the OSM query
                                       did not return any results. In tha case the plugin will pick
                                       a location from the defined pool.
                                       
           34,WPT,32.815956, -118.434157
           34,WPT,32.812891, -118.422278
           34,WPT,32.837133, -118.411639
           34,WPT,32.826139, -118.361292
           34,WPT,32.847135, -118.382658
           34,WPT,32.856550, -118.396460

    ------------------------------------------------------------------------------

    40,text                            just print a message in the mission log

           40,Switch Batteries ON

    ------------------------------------------------------------------------------

    50,command,alt_lo,alt_hi           exec command, below alt_lo or above alt_hi


    ------------------------------------------------------------------------------

    51,alt_lo,alt_hi                   fix command: dropDude / dropSeal

    ------------------------------------------------------------------------------

    52,mode,d1,d2,dist                 place SAR pattern sub-mission into flight plan
                                       flightplan will be stopped and can be continuted afterwards

    ------------------------------------------------------------------------------

    60,dataref,index,val,alt_lo,alt_hi  set dataref[index] to val if AGL <= alt_lo or >= alt_hi

          60,uh60m/conf/pax,0,10           set pax unconditional to 10

          60,uh60m/conf/pax,0,10,0,40      wait until we climb to 40m AGL, then set pax to 10

          !! index=0 means there is no index being used
          !! index=1 means first element in array is addressed

    ------------------------------------------------------------------------------

    61,dataref,index,val_lo,val_hi     wait until dataref[index] <= val_lo or >= val_hi

          61,sim/cockpit2/engine/actuators/fuel_pump_on,2,0,1    waint until pump2 is ON

          !! index=0 means there is no index being used
          !! index=1 means first element in array is addressed

    ------------------------------------------------------------------------------

    81                                  reset mission

    ------------------------------------------------------------------------------

    82                                  discontinuity / stop the flightplan or mission

    ------------------------------------------------------------------------------

    88                                  restart/repeat

    ------------------------------------------------------------------------------

    99                                  NOP


examples:

	10,1,TAC-OPS,123.220

    this defines preset number 1 with frequency 123.220 for a COM unit 
	and adds the tag "TAC-OPS" to it. 

	---------------------------------------------------------------------

    12,1

	this recalls preset 1 on unit COM2

	---------------------------------------------------------------------

    50,uh60/doors/cargo_left_close,0,25

    call command cargo_left_close if ralt >= 25 meter

	---------------------------------------------------------------------

    50,uh60/doors/cargo_left_open,10,0

    call command cargo_left_open if ralt <= 10 meter

	---------------------------------------------------------------------

    32,waypoint,90LOC,0,0,4000,0
    21,ILS-LOWI,111.10
    50,sim/autopilot/approach,0,0


    fly to NAVID 90LOC and change to ALT 4000 ft with default VS

    once reached, set NAV frequency to 111.10 ( ILS LOWI )

    then enter APPROACH mode

	---------------------------------------------------------------------

    60,uh60m/conf/pax,0,3,0,30

    this will set dataref "uh60m/conf/pax" ( index 0 ) to "3" if we climb and reach 30m

	---------------------------------------------------------------------

    61,sim/cockpit2/electrical/APU_generator_on,0,0,1

    this will wait until the APU_generator ( index 0 )  hi-value is "1" or higher

	---------------------------------------------------------------------

	50,uh60/doors/cargo_right_open,30,0

	40,dropping seals
	50,uh60/ops/drop_dude,18,0
	99                                           <--- wait ......
	99
	50,uh60/ops/drop_dude,18,0                   <--- more seals....
	40,dropping more seals
	50,uh60/ops/drop_dude,18,0
	99
	99
	99
	99
	99
	99
	40,removing ropes
	50,uh60/ops/rope_in,0,0                      <---  remove ropes

	50,uh60/doors/cargo_right_close,0,25
	40,Mission HRST completed
	81                                           <--- reset, so a RUN will start the mission again
